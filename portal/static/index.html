부경대학교 컴퓨터인공지능공학부 AI 실습 플랫폼

학과 GPU 서버로 로컬 LLM을 활용할 수 있습니다.

정보전산원에서 발급받은 sk-pknu로 시작하는 키입니다.

실습

아직 주고받은 메시지가 없습니다.

모델을 고르고 질문을 보내면, 답과 함께 첫 응답까지 걸린 시간과 토큰 수가 표시됩니다.

    최근 대화

      모델 상태

      부하는 모델이 한 번에 받을 수 있는 양 가운데 지금 쓰고 있는 비율입니다. 100%에 가까우면 새 요청은 대기열에서 차례를 기다립니다.

      사용량

      최근 요청

      오늘 사용량은 자정(KST)에 0부터 다시 셉니다. 거절된 요청도 원인을 확인할 수 있도록 함께 남깁니다.

      API 안내

      OpenAI 호환 API입니다. OpenClaw 같은 에이전트 도구나 openai 라이브러리에 주소와 키만 넣으면 그대로 동작합니다.

      API 주소
      내 API 키

      OpenClaw

      에이전트는 첫 요청부터 지시문이 길어, 문맥이 8K인 모델로 연결합니다. 설정 파일은 ~/.openclaw/openclaw.json이고 키는 환경 변수 PKNU_API_KEY로 넘깁니다.

      코드뜻할 일
      400대화가 모델의 문맥 길이를 넘었거나 요청 형식이 잘못됐습니다.대화를 줄이거나 문맥이 긴 모델을 고릅니다.
      401API 키가 없거나 틀렸습니다.발급받은 키를 확인합니다.
      404제공하지 않는 모델 이름입니다.모델 상태 화면의 이름을 그대로 씁니다.
      429내 한도(분당 요청, 동시 요청)를 넘었습니다.Retry-After 헤더의 초만큼 기다린 뒤 다시 보냅니다.
      503모델에 요청이 몰렸거나 서버를 점검 중입니다.Retry-After만큼 기다립니다. 계속되면 다른 모델을 씁니다.
